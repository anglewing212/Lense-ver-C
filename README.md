# Lense

macOS 14 及以上的屏幕圈选解答工具，无额外依赖。

## 打开

首次在本机运行 `./scripts/setup-signing.sh` 创建固定的本机签名，以后运行 `./scripts/package.sh` 打包；打开 `dist/Lense.app`，也可把应用拖到“应用程序”文件夹。

应用图标为黑底白圆环；启动后显示在程序坞，可右键图标选择“退出”，也可从应用菜单退出。点击程序坞图标只唤回插件，不自动打开画板。应用包位于 `dist/Lense.app`，压缩包位于 `dist/Lense.zip`；图标源图与 Mac 图标分别在 `Assets/Lense.png` 和 `Assets/Lense.icns`，生成脚本为 `scripts/create-icon.swift`。

1. 无密钥时点击黑圈展开圆角搜索栏，可用 Command + V 粘贴 OpenAI 服务密钥，回车保存并收起。
2. Control + Option 开关透明画板；开启时圆环保持可见，中央显示交叉，可点击关闭。首次截图时允许屏幕录制；不足时仅在画板显示“权限设置”和“重试”，不反复弹出应用提示。如系统要求，退出后重新打开。
3. 拖出方框后松开鼠标，选框保留，可重新拖框；按回车才发送框内截图，AI 在透明画板中原位放置箭头或文本框。发送和解答期间保持画板开启。
4. 在空白处新拖框期间暂时隐藏原答案，Esc 取消选框并恢复原答案；回车才清除旧答案、取消旧任务并发送新选区。没有待确认选框时，Esc 或组合键以约 0.12 秒快速淡出隐藏画板，后台继续解答；再次打开以约 0.12 秒快速淡入显示已保留的答案，并可继续拖框。
5. 拖动圆环时保持鼠标抓取位置，松开后自动吸附最近的屏幕边缘（上、下、左、右）；闲置时缩成贴边扁形，鼠标移近、拖动、画板或密钥输入开启时展开为圆形，离开后再收起。

菜单栏的 ◉ 可打开设置或退出。快捷键冲突时仍可点击圆环。

圆形与贴边扁形通过轻微回弹的系统弹簧动画切换，中途交互从当前显示位置继续，系统“减少动态效果”开启时不播放回弹。思考时默认保持贴边扁形，中央蓝点缓慢闪烁；鼠标移入会展开圆形标志，改用环形加载条且隐藏蓝点；移出再次收起，恢复闪烁蓝点，拖动和密钥输入也可展开。设计参考 [Apple Motion](https://developer.apple.com/design/human-interface-guidelines/motion) 的简短、可打断与尊重辅助设置原则。

## 原位作答

- 单选：正确选项左侧一个水平向右箭头；箭头为深灰色、1px 粗细，无额外描边。
- 多选：每个正确选项左侧分别放箭头。
- 填空：在空格处放单行答案文本框，宽度按完整答案计算；超过整屏宽度的极长答案可横向滚动，不换行。
- 短文：最多五句话；长文：最多十句话。
- 数学：文本框显示计算步骤直到最终答案，较长过程可滚动查看。

文本答案以原题已有的数字前缀开头，例如 `12.` 或 `（3）`；无数字题号时不添加。题号由模型从截图读取，通过独立字段传回；程序统一添加，不参与答案句数计算。文字答案框可直接按住拖到画板内任意位置，内容不变；后续结果更新及画板隐藏/恢复保留手动位置。箭头不支持拖动；空白区域的拖动仍用于选择新问题。

所有文本答案自动排在整个画板的选区外，避开整个题目选区及其他答案。优先完整显示；较窄区域可换行，长答案可滚动。选区占满屏幕、没有可用位置时显示说明，要求缩小选区。选区外只进行几何排版，不额外截图或上传框外内容。

答案统一使用 Times New Roman 10 号，透明、无边框；答案文字统一为深灰色。画板不绘制暗色遮罩，选框仅在四角显示灰色、透明度 50% 的圆点，没有连线。不显示顶部操作提示或作答区外框；错误及权限说明仅在底部出现。思考时缩扁插件中央蓝点闪烁，隐藏画板不停止任务，答案完成后蓝点停止。隐藏画板时，答案完成只保存在后台，不会自动重新打开画板。

AI 使用 `place_arrows` 和 `place_textboxes` 两个画板工具，坐标从截图左上角的 0–1000 换算回本机屏幕。无效位置或超出句数的请求会被拒绝并要求模型修正。看不清时在画板内提示重新圈选。题型与坐标仍由模型判断，需核对答案及标注位置；画板打开期间避免移动原题画面。

## 数据与服务

截图使用 macOS ScreenCaptureKit，直接读取显示器，排除 Lense 自身窗口。截图只保留在内存中，不写文件，不上传框外内容。所选截图和问题发送至 OpenAI；联网搜索由服务按需调用，回答显示来源链接。请求设置 `store: false`，服务仍受供应商数据政策约束。

密钥保存至 `~/Library/Application Support/Lense/.env`，文件与所在目录仅当前账户可访问；不写入应用包，项目已忽略 `.env` 文件。旧钥匙串内容不自动迁移或删除。

固定使用 `gpt-6-astra`，旧版模型设置不再生效。服务与搜索需要账户权限并可能收费。

## 开发与验证

- `./scripts/check.sh`：选区、快捷键、工具参数、坐标换算、句数限制、任务状态及模拟服务的完整工具调用检查；不联网。
- `./scripts/check-app.sh`：使用实际应用控制代码和模拟服务验证隐藏不中断、后台完成后保存答案、停止加载及新一轮取消旧任务；不联网。
- `./scripts/package.sh`：构建正式版并生成应用及压缩包。
- `./scripts/check-signing.sh`：改变副本内容后验证两版仍使用同一固定签名身份。
- 输出针对构建机器架构；当前为 Apple 芯片 Mac。
- 当前使用固定的本机自签证书，证书与专用钥匙串保存在 `~/Library/Application Support/Lense/Signing`（仅当前账户可访问），不写入项目或应用包；不修改系统根证书信任，不改变默认钥匙串。打包缺失证书时直接停止，不回退到临时签名。该目录应保留，删除后重新生成会改变应用身份。
- 从旧临时签名切换到固定签名后可能需要重新授权一次。若系统保留旧 Lense 项目，请在屏幕录制设置中移除旧项并添加当前应用。后续更新是否保留授权仍需实机核对。
- 本机签名用于开发验证；对外分发仍需 Apple 开发者签名和公证。

手动验收：首次权限、桌面及全屏软件、多屏幕与缩放、反向拖框、框外内容不上传、快捷键取消、断网与无效密钥提示、回答与引用、左右吸附。屏幕受保护内容可能无法截图；跨屏选区应在单个屏幕内完成。

接入参考：[OpenAI 工具调用说明](https://developers.openai.com/api/docs/guides/function-calling)、[网页搜索说明](https://developers.openai.com/api/docs/guides/tools-web-search)。

英文题用英文回答；题目明确要求其他语言时遵从题目。单击文本框复制完整答案（含题号），拖动只移动文本框，不复制；移动不能遮挡题目选区。
